# okyanus 🎣

Claude masaüstü ve mobil uygulaması için tatlı bir okyanus teması. Konuşmanın arkasında hareketli bir deniz manzarası var: güneş parlıyor, bulutlar ve martılar süzülüyor, dalgalar akıyor, su altında balıklar yüzüyor. Sağda sarı balıkçı şapkalı turuncu bir maskot sandalda oltasını atmış balık tutuyor, ara sıra göz kırpıyor, şamandırası sallanıyor, arada bir balık sudan zıplıyor. Açık modda açık deniz mavisi, koyu modda derin okyanus tonları gelir. Paneller sahnenin üstünde buzlu cam gibi durur, yazılar okunur kalır.

Sahne geniş pencereden telefon boyuna kadar her ekrana uyar. "Hareketi azalt" ayarı açıksa animasyonlar durur. Terminal ve editörler tema çizmediği için orada görünmez.

## Kurulum

Bir terminal oturumunun komut satırında:

```
/plugin install okyanus --marketplace DuffyDucky/okyanus-tema
```

`Add marketplace?` sorusuna `y` deyin, sonra kapsamı seçin (Enter ile kullanıcı kapsamı).

Kabuktan:

```bash
claude plugin install okyanus --marketplace DuffyDucky/okyanus-tema
```

Masaüstü uygulamasında (`/plugin` orada çalışmaz): istem kutusunun yanındaki + → Plugins → Add marketplace ile `DuffyDucky/okyanus-tema` ekleyin, sonra Add plugin.
